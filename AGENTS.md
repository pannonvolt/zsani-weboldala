# Felhasználói munkaszabályok

## GitHub-feltöltés

- GitHubra kizárólag a felhasználó kifejezett, az adott feltöltésre vonatkozó kérésére tölts fel bármit.
- Egy korábbi feltöltési kérés nem jelent állandó engedélyt a későbbi változtatások feltöltésére.
- A fejlesztés, javítás, helyi mentés vagy tesztelés kérése önmagában nem engedély GitHub-feltöltésre.
- Ez a szabály a git push műveletre és minden GitHub API-n vagy kapcsolt eszközön keresztüli fájl-, commit-, ág- és egyéb projektfeltöltésre is vonatkozik.
- Kifejezett feltöltési kérés hiányában a módosításokat helyben tartsd meg.

A felhasználó kifejezett kérése alapján rögzítve: 2026-10-26.
